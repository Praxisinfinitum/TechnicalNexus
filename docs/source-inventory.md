## Model verification

Brother DCP-T430W: inkjet, maximum paper-tray capacity up to 150 sheets of 80 g/m² plain paper. Source checked on 2026-10-17: [official regional specifications](https://support.brother.com/g/s/id/htmldoc/mfc/cv_dcpt430dw/mexlte/html/GUID-2A5FC4AA-2B7F-4D72-8562-24FF6A146AFD_1.html?lang=en&prod=dcpt236_all). This is paper input capacity, not monthly duty cycle. Other two models pending owner selection.

Reference guide page 1 visibly names DCP-T430W within a family and points to the online user guide for detailed operation and troubleshooting. Its multilingual columns and model-specific control panels require manual layout checks before answer preparation. The online user guide is a next-phase source candidate, not yet imported.

The generic 5 GHz channel supplement does not by itself establish that DCP-T430W supports that band. Licensing and administration guides are not approved maintenance sources. The document manifest records applicability notes and pending status.
